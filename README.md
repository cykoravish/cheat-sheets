# Cheat Sheets

A collection of simple, concise notes for quick learning and revision. Every answer is written the way I would say it to an interviewer: short sentences and simple words.

Each file has only the **most important questions**, and ends with a **Last-Minute Revision** list.

Target role: **Full-Stack Web Developer** (React, Node.js, PostgreSQL).

## Files

## Suggested study order (Full-Stack)

1. **JavaScript core:** `javascript.md`, `javascript-extra.md`, `dom-events.md`
2. **React and TypeScript:** `react.md`, `typescript.md`
3. **Backend and database:** `nodejs-express.md`, `sql-postgres.md`
4. **Coding rounds:** `polyfills.md`, `machine-coding.md`, `dsa-basics.md`, `ui-tasks.md`
5. **HTML and CSS:** `html.md`, `css.md`
6. **Web knowledge:** `web-fundamentals.md`, `performance-security.md`
7. **Scale and tools:** `system-design-scaling.md`, `git-testing-docker.md`
8. **HR round:** `hr-behavioral.md` (read it again the night before)

## How to use

- Read one question, close the file, and **say the answer out loud**.
- Type the code from memory at least once.
- Use the **Last-Minute Revision** at the end of each file on interview day.
