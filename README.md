# Cheat Sheets

A collection of simple, concise notes for quick learning and revision. Every answer is written the way I would say it to an interviewer: short sentences and simple words.

Each file has only the **most important questions**, and ends with a **Last-Minute Revision** list.

## Files

| # | File | What is inside |
|---|---|---|
| 1 | [javascript.md](javascript.md) | Core JS: closures, `this`, prototypes, event loop, Promises, ES6+, basic polyfills |
| 2 | [javascript-extra.md](javascript-extra.md) | `async`/`defer`, `==`, execution context, stale closure, `new`, arrow vs normal, strict mode |
| 3 | [dom-events.md](dom-events.md) | `DOMContentLoaded` vs `load`, `addEventListener`, `target` vs `currentTarget`, key events |
| 4 | [polyfills.md](polyfills.md) | forEach, filter, some, every, call, apply, JSON.stringify |
| 5 | [machine-coding.md](machine-coding.md) | Move zeros, shuffle, fibonacci, deep equal, valid parentheses, string compression and more |
| 6 | [html.md](html.md) | Semantic HTML, DOCTYPE, head, forms, picture and srcset, lazy loading |
| 7 | [css.md](css.md) | Specificity, box model, centering, position, flexbox, z-index, rem vs em |
| 8 | [ui-tasks.md](ui-tasks.md) | Modal, accordion, star rating, autocomplete, toast, infinite scroll, stopwatch |
| 9 | [web-fundamentals.md](web-fundamentals.md) | DNS, what happens on Enter, TCP, HTTPS, REST, JWT, SPA vs MPA, CI/CD |
| 10 | [performance-security.md](performance-security.md) | CDN, caching, SSR/SSG/ISR, Web Vitals, CORS, XSS, CSRF, accessibility, SEO |
| 11 | [hr-behavioral.md](hr-behavioral.md) | Self-intro, project story, teamwork and ownership answers |

## Suggested study order

1. **JavaScript:** `javascript.md`, then `javascript-extra.md` and `dom-events.md`
2. **Coding rounds:** `polyfills.md` and `machine-coding.md`
3. **HTML and CSS:** `html.md` and `css.md`
4. **UI tasks:** `ui-tasks.md`
5. **Web knowledge:** `web-fundamentals.md` and `performance-security.md`
6. **HR round:** `hr-behavioral.md` (read it again the night before)

## How to use

- Read one question, close the file, and **say the answer out loud**.
- Type the code from memory at least once.
- Use the **Last-Minute Revision** at the end of each file on interview day.
